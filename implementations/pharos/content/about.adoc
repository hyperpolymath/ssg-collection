== About Pharos-SSG

Pharos-SSG is part of the poly-ssg ecosystem, demonstrating static site
generation in Pharo Smalltalk.

=== Why Pharo Smalltalk?

Pharo offers a live, image-based development environment where
everything is an object. Its reflective capabilities and powerful IDE
enable rapid prototyping and debugging. Pharos-SSG showcases Smalltalk’s
elegant object model for representing content, templates, and build
pipelines.
